# Setting Up Hugo

Hugo is a fast and flexible static site generator. Here's what makes it great:

- **Fast build times** - Hugo can build sites in milliseconds
- **Simple deployment** - Static files deploy anywhere
- **Markdown support** - Write content in Markdown
- **Powerful themes** - Lots of themes to choose from

## Why Archie?

The Archie theme is minimal, clean, and perfect for blogging.
